# The Style Sphere — Myntra-Style Fashion E-Commerce Website

A complete responsive **front-end fashion e-commerce project** inspired by the shopping flow of modern fashion marketplaces.

## Included features

- Responsive fashion home page
- Men / Women / Kids / Accessories categories
- Product listing page
- Search by product / brand / category
- Category filters
- Product-type filters
- Price filters
- Discount filters
- Sorting by recommended, newest, discount, price and rating
- Product detail page
- Size selection
- Add to Bag
- Quantity increase/decrease
- Remove from Bag
- Wishlist
- Login / Signup demo using LocalStorage
- Checkout address form
- COD / UPI / Card demo payment selection
- Order confirmation page
- LocalStorage cart and wishlist persistence
- Mobile responsive design
- Product images and Google Fonts loaded from the internet

## How to run

### Easiest
Open `index.html` in Chrome.

### VS Code
1. Extract the ZIP.
2. Open the `The_Style_Sphere_Myntra_Style` folder in VS Code.
3. Open `index.html`.
4. Use Live Server if installed, or simply open the file in Chrome.

## Important

This is a **working front-end/demo e-commerce website**. It does not process real payments or connect to a real database. Cart, wishlist and demo login are stored in the browser's LocalStorage.

For a production-level MERN version, connect the same UI to Node.js/Express/MongoDB and a real payment gateway.
